# 🤫 ربات پیام ناشناس

یه ربات تلگرامی برای ارسال پیام ناشناس، که کاملاً روی `Cloudflare Workers` ساخته شده. هرکسی می‌تونه — چه از طریق تلگرام، چه از یه فرم وب عمومی — بدون این‌که هویتش برای شما فاش بشه، بهتون پیام بفرسته؛ و شما هم می‌تونین بدون افشای هویتتون جواب بدین.

بدون نیاز به سرور، بدون نیاز به دیتابیس مجزا — همه‌چیز روی شبکه‌ی edge کلادفلر اجرا می‌شه.

---

## ✨ امکانات

- **دریافت پیام ناشناس** — از طریق لینک اختصاصی تلگرام یا یه صفحه‌ی وب قابل‌اشتراک‌گذاری (فرستنده نیازی به داشتن اکانت تلگرام نداره)
- **پاسخ دوطرفه‌ی ناشناس** — به یه پیام جواب بدین بدون این‌که فرستنده بفهمه شما کی هستین، و برعکس
- **ری‌اکشن** (👍 ❤️ 😂 😮) روی پیام‌ها، که بدون افشای هویت هیچ‌کدوم طرف، دقیقاً به طرف مقابل می‌رسه
- **ذخیره، بلاک و گزارش** برای هر پیام
- **فیلتر کلمات** — رد خودکار پیام‌هایی که حاوی کلمات مشخص‌شده باشن
- **حالت عدم مزاحمت (`DND`)** — توقف دریافت پیام برای ۸ ساعت
- **لینک اختصاصی VIP** — به‌جای یه آیدی تصادفی، `t.me/yourbot?start=your_name`
- **سوال روزانه** — یه پیام زمان‌بندی‌شده‌ی اختیاری که به همه‌ی کاربرا ارسال می‌شه تا دوستاشون رو به پیام‌دادن ترغیب کنن
- **دوزبانه** — فارسی و انگلیسی، قابل انتخاب برای هر کاربر از منوی تنظیمات؛ همه‌ی پیام‌ها، منوها، و حتی فرم وب عمومی خودکار هماهنگ می‌شن
- **آمار** — تعداد بازدید لینک و پیام‌های دریافتی

## 🔐 طراحی امنیت و حریم خصوصی

چون کل هدف این ربات ناشناس‌بودنه، محافظت از هویت یه فکر بعدی نیست — بلکه محدودیت اصلی طراحیه:

- **هیچ‌وقت آیدی واقعی کاربر تو `callback_data` تلگرام قرار نمی‌گیره.** هر دکمه‌ی ری‌اکشن/پاسخ/بلاک یه `token` تصادفی و بی‌معنی حمل می‌کنه؛ نگاشت `token` به آیدی واقعی فقط تو `KV` سمت سرور نگه‌داری می‌شه، با یه زمان انقضا. یعنی حتی اگه یه `callback_data` جایی لو بره، به هیچ اطلاعات قابل‌استفاده‌ای decode نمی‌شه.
- **هیچ اطلاعات حساسی تو کد نیست.** توکن بات موقع اجرا از یه `secret` رسمی کلادفلر (`env.BOT_TOKEN`) خونده می‌شه — هیچ‌وقت تو کد hardcode، لاگ، یا commit نمی‌شه.
- **دفاع چندلایه‌ی کامل‌تر رو باید خودتون تو سطح پلتفرم تنظیم کنین** (بخش [پیشنهادهای امنیتی](#-پیشنهادهای-امنیتی-سخت‌سازی-اختیاری) رو ببینین) — محافظت `DDoS`/`TLS` کلادفلر حملات سطح شبکه رو می‌گیره، ولی کنترل دسترسی سطح اپلیکیشن (مثلاً محدودسازی مسیر `/webhook`) برای یه دیپلوی جدی ارزش اضافه‌کردن داره.

## 🏗️ معماری

| بخش | فناوری |
|---|---|
| اجرا | `Cloudflare Workers` (بدون سرور، `V8 isolates`) |
| ذخیره‌سازی | `Cloudflare Workers KV` (اطلاعات کاربر، نگاشت لینک‌ها، توکن‌های ناشناسی) |
| رابط بات | `Telegram Bot API` (مبتنی بر `webhook`) |
| رابط وب | یه صفحه‌ی `HTML` استاتیک که برای هر کاربر رو مسیر `/p/<linkId>` سرو می‌شه و به `/api/send` پست می‌کنه |
| زمان‌بندی | `Cloudflare Cron Triggers` (برای ارسال سوال روزانه) |

همه‌چیز تو یه فایل `worker.js` واحده — بدون نیاز به `build`، فریم‌ورک، یا `dependency`.

## 🚀 راه‌اندازی

### پیش‌نیازها

- یه [حساب کلادفلر](https://dash.cloudflare.com/sign-up) (پلن رایگان برای اکثر استفاده‌های شخصی کافیه)
- [`Node.js`](https://nodejs.org/) و [`wrangler`](https://developers.cloudflare.com/workers/wrangler/) نصب‌شده (`npm install -g wrangler`)
- یه توکن بات تلگرام از [`@BotFather`](https://t.me/BotFather)

### ۱. کلون و تنظیم پروژه

```bash
git clone <this-repo-url>
cd anonymous-message-bot
```

یه فایل `wrangler.json` (یا `wrangler.toml`) تو ریشه‌ی پروژه بسازین:

```json
{
  "name": "anonymous-message-bot",
  "main": "worker.js",
  "compatibility_date": "2026-06-20",
  "kv_namespaces": [
    { "binding": "ANON_STORE", "id": "<your-kv-namespace-id>" }
  ],
  "triggers": {
    "crons": ["0 8 * * *"]
  }
}
```

`KV namespace` رو بسازین:

```bash
wrangler kv namespace create ANON_STORE
```

`id`ای که برمی‌گرده رو تو `wrangler.json` کپی کنین.

### ۲. توکن بات رو به‌عنوان secret تنظیم کنین

**هیچ‌وقت توکن بات رو تو کد نذارین.** به‌جاش با دستور زیر به‌صورت رمزنگاری‌شده تو کلادفلر ذخیره‌ش کنین:

```bash
wrangler secret put BOT_TOKEN
```

وقتی ازتون خواست، توکنی که از `@BotFather` گرفتین رو پیست کنین.

### ۳. دامنه‌ی لینک وب رو به‌روز کنین

نزدیک ابتدای `worker.js`، این ثابت رو با دامنه‌ی واقعی دیپلوی‌شده‌ی خودتون (ساب‌دامین `*.workers.dev` یا دامنه‌ی اختصاصی) جایگزین کنین:

```js
const WEB_BASE_URL = "https://your-worker-name.your-subdomain.workers.dev";
```

### ۴. دیپلوی

```bash
wrangler deploy
```

### ۵. ثبت webhook تلگرام

تلگرام رو به سمت `Worker`ی که دیپلوی کردین هدایت کنین:

```bash
curl "https://api.telegram.org/bot<YOUR_TOKEN>/setWebhook?url=https://your-worker-url/webhook"
```

### ۶. (اختیاری) فعال‌سازی سوال روزانه

`cron trigger`ی که تو مرحله‌ی ۱ تو `wrangler.json` تنظیم کردین، بعد از دیپلوی خودکار مسیر `/cron` رو زمان‌بندی‌شده صدا می‌زنه — کار اضافه‌ای لازم نیست.

## 🧑‍💻 نحوه‌ی استفاده

۱. کاربرا با ربات چت رو شروع می‌کنن و `/start` می‌زنن تا لینک اختصاصی ناشناسشون رو بگیرن (هم لینک تلگرام، هم لینک وب عمومی).
۲. این لینک رو با دوستاشون به اشتراک می‌ذارن.
۳. هرکسی که این لینک رو باز کنه — چه از تلگرام، چه از یه مرورگر ساده — می‌تونه بدون اکانت یا هیچ ردی از هویتش، پیام بفرسته.
۴. گیرنده می‌تونه از دکمه‌های زیر هر پیام، بهش ری‌اکشن بده، ناشناس جواب بده، ذخیره‌ش کنه، بلاک کنه، یا گزارش بده.
۵. زبان (فارسی/انگلیسی) برای هر کاربر از بخش **تنظیمات** قابل انتخابه.

## 🔧 پیشنهادهای امنیتی (سخت‌سازی اختیاری)

این‌ها به‌صورت پیش‌فرض پیاده‌سازی نشدن، ولی برای یه دیپلوی جدی ارزش اضافه‌کردن دارن:

- **تأیید اصالت webhook**: موقع صدا زدن `setWebhook` تلگرام یه `secret_token` تنظیم کنین و هدر `X-Telegram-Bot-Api-Secret-Token` رو تو هر درخواست به `/webhook` چک کنین؛ هرچی مطابقت نداشت رد کنین.
- **محدودسازی نرخ درخواست (`rate limiting`) رو `/api/send`**: برای جلوگیری از سوءاستفاده از فرم وب عمومی، محدودیت بر اساس `IP` یا لینک اضافه کنین.
- **`Cloudflare Access`**: اگه روی این پروژه یه پنل مدیریتی اضافه کردین، به‌جای پیاده‌سازی دستی احراز هویت، از [`Cloudflare Access`](https://developers.cloudflare.com/cloudflare-one/policies/access/) استفاده کنین.
